## ✨ Características

- 🌌 **Fondo de red animado** en `<canvas>` que reacciona al movimiento del mouse.
- ⌨️ **Terminal interactiva** con comandos (`help`, `about`, `skills`, `proyectos`, `neofetch`, `contacto`…), historial con ↑ ↓ y autocompletado con Tab.
- 📡 **Datos en vivo** desde la API de GitHub: número de repositorios, lenguaje y última actualización de cada proyecto.
- 🧩 **Stack filtrable** por categoría con animaciones.
- 🎴 Tarjetas con efecto **spotlight** y **tilt 3D**, botones magnéticos y animaciones al hacer scroll.
- 📱 **Responsive** y accesible: navegación con teclado, `prefers-reduced-motion` y HTML semántico.
- 🥚 Easter eggs: prueba el comando `matrix` o el código Konami (↑ ↑ ↓ ↓ ← → ← → B A).

## 🛠️ Ejecutar en local

No necesita dependencias ni compilación. Basta con un servidor estático:

```bash
python -m http.server 8000
```

Luego abre `http://localhost:8000`.

## 🌐 Despliegue

El sitio se publica automáticamente con **GitHub Pages** desde la rama `main` en
